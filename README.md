# 森林之子服务器租用：几核几G够用、UDP端口怎么开，8人联机长期存档不丢档

搜“森林之子服务器租用”的人，十有八九是卡在同一个问题上：官方的专用服务端工具是免费的，那我到底该租一台什么样的机器？答案比想象中窄——因为 Sons Of The Forest Dedicated Server 目前仍然只给 Windows 版本，选错系统再高的配置也白搭。

## 先确认系统：这一步能淘汰一半方案

Steam 上的 Sons Of The Forest Dedicated Server 是独立免费工具（App ID 2465200），不需要再买一份游戏本体。但官方配置指南给的是 Windows 目录结构（`%LocalAppData%\..\LocalLow\Endnight\SonsOfTheForestDS`），Linux 上要用 Wine 兼容层才能跑，属于能实验但不被官方支持的路子。

所以租服务器时的第一条筛选条件是：**能不能装 Windows**。雨云的云服务器和游戏云 VPS 都支持 Windows/Linux 镜像随时重装，这一条能满足。

这台服务端默认要用到三个 UDP 端口：

- `8766`：游戏主端口
- `27016`：服务器列表查询
- `9700`：world blob 同步

雨云的游戏云 VPS 是 NAT 机型，共享公网 IP，但允许自定义开放 15 个端口映射。开森林之子只需要用掉其中 3 个，剩下 12 个还能顺手开点别的。

## 8 人是硬上限，配置要按“世界”买而不是按人头买

官方 `MaxPlayers` 的配置范围是 1–8。看到“支持 16 人、32 人”的写法可以直接略过，那是民间改参数，不是官方支持范围。

真正吃资源的是存档状态：基地建得越大、游戏天数越久，内存就越往上走。参考数据是 30 个游戏日以上、建筑密集的存档，内存会额外多吃 500–800MB。CPU 那边看的不是核心数而是单核频率，因为服务端是 Unity 那套架构，主线程一堵，全服一起卡。

| 使用场景 | 建议起步配置 | 硬盘 |
| --- | --- | --- |
| 2–4 人，纯净存档 | 4 核 3.0GHz 级 / 6–8GB 内存 | 80–100GB SSD |
| 5–8 人，纯净长期存档 | 4 核高主频 或 8 核 / 8–12GB | 120–150GB SSD |
| 带模组、大地图、重度建造 | 12GB 以上内存，CPU 留出余量 | 150GB+ |

注意最后一行：模组把配置直接推高一档，这也是很多人一开始买得太省、玩到中期被迫重新租的原因。

## 自己用 PC 开服，和租一台，哪个划算

自己开服不是不行，但它有个前提条件：只要有人在玩，你的电脑就不能关。真正的成本大概是这样的——24 小时开机的电费一年 120–350 美元，公网线路一年 0–300 美元（要固定 IP 或商业线路就更贵），硬件摊销一年 150–400 美元。合起来一年 300–1000 美元，还没算上你更新、处理崩溃、做备份花掉的时间。

## 配置里最容易翻车的两个点

第一是 `SaveMode`。官方定义很直白：`Continue` 会在 slot 存在时加载、不存在时新建；而 `New` 会直接覆盖指定 slot，而且只要你一直留着 `New`，每次重启都会再覆盖一次。测试新世界时用 `New` 没问题，确认世界创建好之后立刻改回 `Continue`，别让它留在生产配置里。

第二是启动时的 Self Test。它检测的是 UDP 8766、27016、9700 三条端口链路能不能通。跳过检测不等于玩家真能进来，用 NAT 机型的时候尤其要确认这三个端口都做了映射——否则你自己能连、朋友连不上。

最后补一句备份习惯：整个服务端目录（含 `dedicatedserver.cfg`、`SonsGameSettings.cfg`、`logs` 和存档）最好按周期打包一份。雨云的游戏云 VPS 自带备份功能，配置改好、世界稳定之后做一次快照，成本比重新开荒低得多。

## 常见问题

**森林之子服务器最多几个人？**
官方 `MaxPlayers` 配置范围是 1–8，8 人是引擎侧的实际上限。

**一定要 Windows 吗？**
目前的专用服务端工具仍标注为 Windows。Linux 路线要用 Wine，属于自建实验方案，官方不提供支持。

**雨云的大陆机房需要备案吗？**
官方说明里要求“域名备案 + 过白”的是大陆机房走域名访问的 HTTP 业务。游戏服务端是玩家用 IP 加端口直连 UDP，不涉及域名解析。

**配置不够会怎样？**
服务端 TPS 会往下掉，表现是建造、砍树、开门这些操作出现延迟感，怪物和 NPC 的行为也会变钝。出现这种情况通常是内存或单核频率撞到天花板，而不是宽带不够。
